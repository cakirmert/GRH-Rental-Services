# Documentation screenshots

These are captures of the isolated application using public catalog content and
synthetic private records. They illustrate the interface rather than proving a
production deployment.

The selected gallery includes the catalog, booking form and staff calendar.
Keep live account totals, member lists, private booking details and operator
settings out of published screenshots.

To refresh them, follow the root README's local database setup, build and start
the guarded site, then run the browser preview checks. Review the generated
images before copying selected captures into this folder. Never substitute
authenticated production captures.
